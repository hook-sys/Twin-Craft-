# legacy/

The v1 application, kept for reference while Aladeen is rebuilt.

Nothing in here is compiled, routed or deployed — `tsconfig.json` and the
ESLint config both exclude this folder. It exists so Phase 3 can lift the
eight template designs out of `legacy/components/…` and the ERP screens out of
`legacy/app/dashboard/` rather than reinventing them.

Delete it only once the rebuild has replaced every piece it holds.
